REZA ASESORES | Borrador web
============================

ESTRUCTURA
- index.html        Página principal (sitio tipo landing page con navegación por secciones)
- css/style.css     Diseño visual, responsive y animaciones
- js/main.js        Menú móvil, navegación, efectos, WhatsApp y formulario

CÓMO PREVISUALIZAR
1. Extrae la carpeta del ZIP.
2. Abre index.html en Chrome, Edge o Firefox.
3. Se recomienda conexión a internet para cargar tipografías e imágenes remotas.

CONFIGURACIÓN IMPORTANTE ANTES DE PUBLICAR
Abre js/main.js y revisa esta línea:
const WHATSAPP_NUMBER = '526565261298';

El número se tomó del contacto de cotizaciones compartido para REZA ASESORES. Confirma que sea el número correcto y que tenga WhatsApp. Debe escribirse con código de país, sin +, espacios ni guiones.

FORMULARIO
El formulario valida los campos en el navegador y prepara un mensaje con los datos para abrir WhatsApp. El visitante todavía debe pulsar ENVIAR dentro de WhatsApp. No almacena datos ni los envía a un servidor. Para producción se recomienda integrar un backend seguro o CRM y publicar un aviso de privacidad completo.

CONTENIDO PENDIENTE DE VALIDACIÓN
- Confirmar número de WhatsApp y teléfono de atención.
- Confirmar cuáles productos, coberturas y tipos de fianza comercializa actualmente REZA ASESORES.
- Sustituir las imágenes de muestra por fotografías con licencia o material autorizado de la agencia.
- Sustituir el logotipo tipográfico provisional por el archivo maestro oficial del logo.
- Incorporar el aviso de privacidad real y su enlace.
- Confirmar domicilio, horarios, redes sociales y aseguradoras/afianzadoras que se pueden mencionar.
- Revisar textos y condiciones con la agencia antes de publicación. No se muestran primas ni coberturas como promesas garantizadas.

DISEÑO
La paleta usa principalmente blanco, gris cálido y neutros; el vino #500024 y el rosa #BE2955 aparecen como acentos para conservar la identidad sin dominar el sitio. Tipografías: Manrope y DM Sans.
